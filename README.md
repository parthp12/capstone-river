# capstone-river
River Crossing Puzzle Game. 

Instructions: 
To run the file in terminal use python rivergame.py
For to move an item type what you would like to move. 

Rules for the game:
A farmer needs to cross from the north side of a river to the 
south side of it and take a Fox, a Chicken and his Seeds. 
However, his boat can only take one item at a time and he needs to 
be on the boat to take it across. 
If the Fox is left alone with the Chicken, the Fox will eat the Chicken.
If the Chicken is left alone with the Seeds, the Chicken will eat the Seeds.
If the Farmer is there the Chicken is safe from the Fox.
If the Farmer is there the Seeds are safe from the Chicken.
